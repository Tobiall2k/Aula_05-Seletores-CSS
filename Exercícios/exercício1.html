Seletores Compartilhados

Seletor de Atributo

O seletor a partir de atributo é usado para estilizar elementos HTML através de atributos específicos do mesmo

Exemplo:

            
        a[target] {
            background-color: yellow;
        }

Seletor Descendente

O Seletor de Descendentes é usado para estilizar elementos HTML através de outros elementos

Exemplo:

            
        div p {
            background-color: yellow;
        }

Seletor Filho Direto

O Seletor Filho Direto é usado para estilizar elementos HTML através de outros elementos, porém apenas a filhos diretos, e não a netos e outros elementos, ou seja, aqueles que estão diretamente dentro da classe pai

Exemplo:

            
       div > p {
            background-color: yellow;
        }

Seletor Adjacente Direto

O Seletor Adjacente Direto é usado para estilizar elementos HTML através do elemento que precede o que se quer estilizar

Exemplo:

            
       div + p {
            font-size: 20px;
        }

Seletor de Irmãos Gerais

O Seletor de Irmãos Gerais é usado para estilizar elementos HTML através de um elemento pai em comum

Exemplo:

            
       div ~ p {
            margin-top: 10px
        }

Seletor Universal

O Seletor Universal é usado para todos estilizar elementos HTML dentro de uma página

Exemplo:

            
       * {
            margin: 0;
            padding: 0;
            border: 0;
        }

Seletor de Pseudoclasse

Seletor de Pseudoclasse é usado para estilizar elementos HTML através do estado atual do mesmo

Exemplo:

            
       a:hover {
            color: purple;
        }

Seletor de Pseudoelemento

Seletor de Pseudoelemento é usado para estilizar elementos HTML através de partes específicas, como primeira linha, primeira letra e outros.

Exemplo:

            
       p::first-letter {
            font-size: 200%;
        }
